# VetDiary

## Project Overview
VetDiary is a simple veterinary diary web application built with **ASP.NET Core MVC**.  
The system allows managing pet owners, animals, and basic medical visit records.

---

## Technologies
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Razor Views

---

## Setup
1. Clone repository  
2. Open solution in editor  
3. Configure **connection string** in `appsettings.json`  
4. Run migrations
```
dotnet ef database update
```
5. Run project
